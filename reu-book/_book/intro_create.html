Types of data

In R, there are five types of data we may enctouner. Of these five, we commonly encounter two to three, depedning on what you are doing. These include: numeric, character, logical, integer, and complex.

Numeric

Numeric is for, you guessed it, numbers. Within a data frame, numeric sometimes express as “double”.

# create a variable that is numeric  
x <- 10
[1] "numeric"
Note

In these code examples, the object type will print below the code. I have set it to do so using some hidden code. This will be consistent for the examples that follow below.

Character

If I wrap a number, word, or string of words with quotations, they are considered a character-type variable. When creating a character, you can use “quotation marks” or ‘apostrophes’.

# create characters using three examples 
x <- "character"
y <- '10'
z <- "all one object"
[1] "character"
[1] "character"
[1] "character"
Caution

If you attempt to combine a quotation mark with an apostrophe, your code will break. See the example below.

broken_name <- "x'

1: broken_name <- "x'

                  ^

Logical

Logical operators comprise out TRUE and FALSE statements.

Important

What happens when you do not use full caps for either true or false? Copy and paste the commented code into a script and see.

y <- FALSE 
#x <- true
#class(true)
[1] "logical"
[1] "logical"

Integer

Integers are whole numbers without any fraction or decimal part. There are denoted in R by following a number with the uppercase letter “L”.

# assign an integer
x <- 10L
[1] "integer"

Complex numbers

Last, but not least, is the complex number. In our day-to-day wrangling and visualization, we seldom encounter this. However, it is important to know that complex numbers exist in R.

# i for imaginary 
x <- 10i
[1] "complex"

### Types of data {.unnumbered}

In R, there are five types of data we may enctouner. Of these five, we commonly encounter two to three, depedning on what you are doing. These include: **numeric, character, logical, integer, and complex.**

Numeric is for, you guessed it, numbers. Within a data frame, numeric sometimes express as "double". 

```{r}

x <- 10
```
